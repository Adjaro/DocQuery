# KpiCard

Chiffre clé : un libellé, une valeur, et de quoi la juger. Sans cadre ni icône.

**Fournir** : `label`, `value` (formaté à la française : espace des milliers, virgule décimale), `unit`, `delta` + `deltaTone` (`bon` ou `mauvais` selon le sens métier, pas le signe), `hint` (objectif, seuil, comparaison).

- Aligner 3 ou 4 chiffres clés sur une ligne, entre deux filets.
