# Citation

Citation : la source d'une affirmation, sous forme de note numérotée. Un clic surligne le passage dans le document.

**Fournir** : `n`, `source` (fichier ou table), `location` (page, §, colonne), `quote` (extrait verbatim, facultatif), `active` + `onClick`.

- Dans le texte, l'appel de note est un `button.ak-ref` portant le même numéro.
- Les citations suivent la réponse, sans cadre. Dans le document, le passage est un `mark.ak-hl` ; seul le passage actif (`ak-hl-active`) est surligné.
